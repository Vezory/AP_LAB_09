### Завдання 9.1: Простори імен
Обчислення суми ряду Тейлора для функції $\ln(x)$ при $x > 0$:
$$\ln x = 2 \sum_{n=0}^{\infty} \frac{1}{2n+1} \left(\frac{x-1}{x+1}\right)^{2n+1}$$
